## 首轮生成与验收

1. 先用角色净图或正面站姿生成一个带纹理、未绑骨的模型，优先检查相似度；多视图仅在外观一致且平台支持时使用。
2. 原图与真实 GLB 渲染在同角度、相近光照下并排对比：脸型与眼睛、刘海与头发轮廓、头身比例、发饰、服装与披风。
3. 同时查看侧面、背面及无纹理几何，排除只靠正面贴图造成的假相似。
4. 未通过相似度验收的模型不进入绑骨和项目接入。
5. 通过后再处理网格、材质、骨骼与动作。大头比例、披风和手指需要实际播放动画检查。
