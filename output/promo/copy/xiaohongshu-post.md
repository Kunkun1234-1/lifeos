## 图文正文

我一直不太满意传统的效率工具。

待办告诉我“今天要做什么”，日历告诉我“时间放在哪里”，目标工具记录“以后想去哪里”，记账 App 只留下数字——但它们彼此不知道对方的存在。

所以我做了 LifeOS。

它把 PARA、GTD、OKR、项目、日程、笔记、复盘和个人资产放进同一套系统。任务完成后，不只是打一个勾，还会结算 XP、金币、属性与成就；长期目标也不再停留在愿望清单里，而是能被拆到项目、任务和每一天的日程中。

更特别的是，它不只给人用。

目前项目提供 93 个 MCP 工具，ChatGPT / Agent 在用户授权后，可以查询任务与目标、创建计划、完成行动、写复盘、处理资产和游戏化功能。写操作带权限、审计与幂等保护，不是把数据库直接暴露给 AI。

技术栈是 Next.js 15、React 19、PostgreSQL、Prisma、Auth.js、OAuth 2.1 和 MCP。Web 与业务 API 可以独立部署。

现在它已经正式开源，采用 MIT License。仓库完成了密钥轮换、Git 历史清理、CI、构建与部署验证，也启用了 GitHub Secret Scanning 和 Push Protection。
