# 原有美术资源

本包归档项目现有的 112 个图片、SVG 和祈愿动画文件，保留原来的目录层级。它们没有重新生成，文件与原资源一致。

- `lifeos/`：背景、默认头像、领域插画、装饰与功能插画。
- `life-game/`：角色、侧栏背景、个人面板和旧道具。
- `gacha/`：祈愿背景、动画及旧奖励道具。
- `manifest.json`：原地址与艺术包内的地址映射。

当前背包道具使用 `../anime-rpg-v1/items/`。这里的旧道具用于来源归档与兼容追踪；不要把旧道具设回默认素材。旧 URL 由 `../legacy-urls.json` 和 Next.js rewrites 兼容，原目录的重复美术文件已移除。
