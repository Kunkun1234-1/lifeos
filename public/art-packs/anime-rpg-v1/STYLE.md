# anime-rpg-v1 美术规范

状态：2026-10-07 用户认可并固定的道具风格。

视觉基准：`sources/approved-inventory-sheet.png`。以这张认可的第二版原图为准，不使用第一版的繁复金属风格。完整生成提示词保存在 `sources/generation-prompt.txt`。

## 画法

- 精致而简练的二次元 RPG 手绘道具图标，轻盈、略有棱角，轮廓在小尺寸仍然清晰。
- 细致且克制的深色轮廓线；大色块加两到三组明确明暗，保留柔和的手绘过渡和少量表面纹理。
- 纸、布、皮革、陶瓷以哑光质感为主；晶体用概括的切面，金属只用少量局部高光。
- 每类道具有自己的本色和主题：朱红纸券、深绿皮书、蓝紫宝石、青色晶笔，不强迫所有物品使用蓝金配色。
- 魔法光效仅服务于主体识别，克制使用；不要大光晕、烟雾、满屏星屑。
- 统一为轻微的三分之四视角、完整主体、居中构图。图标素材具有透明余白，名称和稀有度由界面显示。

## 禁止偏离

不做摄影式产品图、写实 3D 渲染、塑料玩具或 emoji。避免油亮金属、满身镀金、繁复巴洛克雕花、厚重体积、密集细节和电影式照明。不把紫色卡片背景、中文名称或星级嵌入独立素材。

## 认可素材与来源

`items/` 下 20 张图直接从认可原图提取，透明化和留白是资源处理，不是重新设计。它们为 256 × 256 无损 WebP，原始画面的物品有效分辨率约为 150–220 像素，适用于背包图标和当前详情展示。

裁切坐标与来源记录：`sources/extraction.json`。复现命令（项目根目录）：

```sh
node scripts/extract-inventory-art.mjs
```

## 皮肤与背景

`skins/` 与 `backgrounds/` 是本包后续资产的固定存放位置。将来新生成的同包素材延续上述手绘、克制材质与配色原则；已有背景与角色图目前位于 `../legacy-lifeos/`，不能把它们视为已经按本规范重绘。

## 全部功能入口

功能插画也采用同一物件画法。使用任务册、日历、幼苗、书籍、地图、靶子、图表册、工具包、礼盒和背包等明确主题表达功能；用浅色界面底与独立透明物件组合。避免把森林、山谷、天空、宏大场景或摄影式柔光作为功能卡片的默认图片。

已有匹配的认可道具直接复用，避免重复生成和复制。新功能物件存入 `feature-art/`，PNG 原图与提示词存入 `sources/feature-art/`；名称与描述仍由界面显示。完整来源与映射见 `feature-art/README.md` 和 `manifest.json` 的 `featureArt`。
